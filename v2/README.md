# 大華中學校園飛越 · 第二版

依使用者提供的 `videoplayback.mp4` 在 00:16 之後的多角度空拍畫面，重新建立校園的可編輯 Blender 場景。先檢視 29 張間隔取樣畫面，再保留 8 張指定時間影格作為配置依據。沒有宣稱逐一人工檢視所有原始影格，也不是攝影測量重建。

## 交付

- `dahua-campus-detailed.blend`：Blender 5.3 場景，含 576 幀、24 fps、24 秒鏡頭動畫。
- `dahua-campus-1080p.mp4`：1920 × 1080、H.264 完整飛越影片。
- `build_detailed_scene.py`：可重建場景的完整腳本。
- `reference/`：8 張來自使用者影片的指定時間影格。

## 依影片修正

| 影格 | 可辨認的資訊 | 對應調整 |
| --- | --- | --- |
| 00:16、00:24 | 前庭草坪、校門、右前方體育館、紅色斜屋頂 | 補上體育館、彎曲環校車道、前庭與屋脊 |
| 00:40 | 教學樓從反面看見的相對位置 | 改為兩條平行教學樓與中央連接廳 |
| 00:56 | 跑道直線區、藍色邊帶、看台、兩面籃球場 | 重做體育設施幾何與標線 |
| 01:28 | 體育館側面、看台高差、後方校舍 | 補上窗帶、階梯、中央遮棚 |
| 01:44 | 後方白色校舍、綠色屋頂建物及施工區 | 加上平頂女兒牆、屋頂設備和後方建物 |
| 01:56、02:08 | 校門車道、前庭、連接關係 | 核對正反兩側視角與動畫構圖 |

窗框、簷口、走廊欄杆、屋面接縫、樹冠、路燈與停車車輛以可編輯幾何建立。各建築依用途分成獨立物件，樹木共享網格以降低檔案與渲染負擔。

影片本身為 640 × 360，尺寸、樓層細部、背面與地形仍有估計成分。1080p 是新模型的原生渲染解析度，並未把低解析度原片當作高解析度模型貼圖。

## 重新建置

```sh
blender -b --python build_detailed_scene.py
```

在 Blender 開啟場景後，攝影機為 `Aerial camera`，影格範圍 1–576，渲染器為 Eevee。原始影片不包含在此 repo 中；參考影格保留來源時間。
